# Licenses for bundled CAD components

GoggleLab distributes the `occt-wasm` 4.3.2 TypeScript wrapper and its separately
loaded `occt-wasm.wasm` runtime resource.

The wrapper is Copyright (c) 2026 Andy Mai and is offered under MIT OR Apache-2.0.
The WASM is built from Open CASCADE Technology and is LGPL-2.1-only with the Open
CASCADE exception. The complete corresponding source, exact revisions, build scripts,
and replacement instructions are generated by `scripts/prepare-cad-source.py`.

These tracked texts are inputs to `scripts/prepare-licenses.py` because the published
`occt-wasm` npm tarball declares its licenses but does not carry their files:

- `occt-wasm-MIT.txt`
- `occt-wasm-APACHE-2.0.txt`
- `LGPL-2.1-only.txt`
- `OCCT-LGPL-exception-1.0.txt`
